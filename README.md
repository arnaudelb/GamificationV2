# Gamification — prototype personnel

## Publication sur GitHub Pages
Téléversez **le contenu de ce dossier** dans la racine du dépôt GitHub : `index.html`, `manifest.webmanifest`, `sw.js` et le dossier `assets`.

La page d'accueil utilise `assets/never-give-up.png`. Les icônes PWA requises pour Chrome Android sont dans `assets/icon-192.png` et `assets/icon-512.png`.

Dans GitHub, activez Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Après remplacement des fichiers, rechargez le site sur le téléphone. Si l'ancienne version reste en cache, fermez Chrome puis rouvrez la page, ou effacez les données du site pour cette adresse.

Les données de l'application sont conservées localement sur l'appareil et ne sont pas synchronisées. Exportez régulièrement une sauvegarde depuis Options.
